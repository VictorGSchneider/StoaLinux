screen-toolkit: add configurable screenshot delay

Adds a new integer pluginSetting `screenshotDelaySec` (default 0,
clamped 0-60). When > 0, the three annotate launch timers wait the
configured number of seconds before invoking grim, so the user has
time to compose the screen.

* Settings.qml — load/save the value, expose it via a small numeric
  input in its own "Screenshot" section above "Share".
* Main.qml — derive `_screenshotDelayMs` from the setting and add it
  to the three launchAnnotate*/interval fields.
* i18n/en.json — add `settings.screenshotDelay` and
  `settings.screenshotDelayDesc`.

Default 0 preserves the current behaviour bit-for-bit.
